# NDSU Design Readiness Assessment — UDI brand kit edition

This folder is ready to publish with GitHub Pages.

## Contents

- `index.html` — the complete standalone assessment site, including the executive summary, interactive dashboard, methodology and resources; its visual system follows the June 2026 UDI Brand Kit
- `assets/udi-logo-white.png` — the official University Design Institute / Arizona State University logo used by the page

## Publish to GitHub Pages

1. Copy `index.html` and the `assets` folder into the root of the `NDSUDesignImperativeAssessment` repository.
2. Commit and push the changes to the branch used by GitHub Pages.
3. Confirm that Pages is configured to publish from the repository root.
4. Open the published URL and refresh once the deployment completes.

The site has no build step and no external code dependencies. Keep the `assets` folder beside `index.html` so the UDI logo resolves correctly.

## Brand implementation

This edition uses UDI blue (`#00A3E0`) as the leading color, supported by rich black, white, gray and gold. It uses Neue Haas Grotesk with Arial as the system fallback, sentence-case headings, left-aligned copy, the approved white UDI lockup on dark backgrounds, and a blue dotted-ring motif derived from the brand kit's visual language.

## Data boundary

The page presents aggregate assessment results only. It does not include individual respondent records.
